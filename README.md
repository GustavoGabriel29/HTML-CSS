
# 🏦 Banco Digital

![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)

**Banco Digital** é um projeto web que simula operações básicas de um sistema bancário, permitindo que o usuário consulte saldo, faça depósitos, realize saques e interaja com uma interface moderna e responsiva.

---

## ✨ Funcionalidades

- 💰 Consultar saldo em tempo real  
- 🏦 Depositar valores com atualização imediata  
- 💳 Sacar valores com validação de saldo  
- 📱 Layout responsivo, adaptável para dispositivos móveis  
- 🎨 Interface moderna com gradiente e efeitos de hover  

---

## 🛠 Tecnologias Utilizadas

- **HTML5** - Estrutura da aplicação  
- **CSS3** - Estilização e design responsivo  
- **JavaScript** - Lógica das operações e manipulação do DOM
